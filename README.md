# Graphanta v0.6.0-alpha.2

数学的な思考と表現を支援する、ローカルファーストの作図アプリです。

## 開発環境での起動

```bash
npm ci
npm run dev
```

`app.html`はViteの開発用入口です。リポジトリ直下の`index.html`は、ビルド済みの単体起動版です。

## 公開用ファイルの生成

```bash
npm run build
```

ビルド時に、Viteの生成物からCSSとJavaScriptを埋め込んだ単体版を作成します。

- リポジトリ直下の公開・ローカル起動用: `index.html`
- 検証用生成物: `dist/index.html`

GitHub Pagesは **Deploy from a branch / main / /(root)** を選択してください。Actionsワークフローは使用しません。`index.html`は通信なしで直接開けます。

公開用ZIPには次を収録します。

- `index.html`: `file://`と静的Web配信の共通入口
- `sw.js`: Web配信時のオフライン再起動用
- `manifest.webmanifest`: Webアプリの基本情報
- `README.md`: 起動・公開・変更内容

ローカル利用ではZIPを解凍して`index.html`を開きます。Web公開では4ファイルを同じ階層へ配置してください。

## GitHubで残すファイル

GitHub Pagesで**実行するだけ**なら、実行本体は`index.html`です。Web配信時のオフライン再起動とWebアプリ情報を維持するため、`sw.js`と`manifest.webmanifest`も同じ階層へ残すことを推奨します。`README.md`は実行には不要ですが、公開ページの説明として残します。

今後もこのリポジトリを開発元として使う場合は、さらに`src/`、`scripts/`、`app.html`、`package.json`、`package-lock.json`、`tsconfig*.json`、`vite.config.ts`を残してください。`.gitignore`、`AGENTS.md`も開発運用上は残すことを推奨します。`CODEX_START.md`だけは実行・ビルドのどちらにも必須ではなく、GitHub連携でCodex開発を再開する予定がなければ削除できます。

## v0.6.0-alpha.2の主な変更

- オブジェクトの表示／非表示切替時に、一覧行と目アイコンへ短い視覚フィードバックを追加しました。再表示時はキャンバス上でも軽くフェードインします。
- `prefers-reduced-motion`を尊重し、動きを減らす設定ではアニメーションを無効化します。
- オブジェクトウィンドウへ固定／固定解除ボタンを追加し、複雑な図で意図しない移動や変形を防ぎやすくしました。
- 非表示にしたオブジェクトは選択状態から外し、非表示後に選択枠だけが残らないようにしました。
- オブジェクト一覧の補足表示を「種類・固定・非表示」の複合表示にし、状態を一覧だけで把握しやすくしました。
- `locked` / `hidden` は既存の保存項目をそのまま利用するため、プロジェクト保存形式の互換性を維持します。

## 数式入力の基本

| 入力 | 表示 |
|---|---|
| `a/b` | 分数 |
| `x^2` または `x^(n+1)` | 上付き |
| `a_1` または `a_(n+1)` | 下付き |
| `sqrt(x+1)` | 平方根 |
| `abs(x)` | 絶対値 |
| `frac(a+b,c-d)` | 分数 |
| `sqrt(b*x^2)/(a-1)/x` | 複分数 |

現在の構文はGraphanta独自の軽量形式です。将来の数式構造エディターでも、この保存形式を読み込めるよう互換性を維持します。

## 関数グラフ

グラフの軌跡を選択すると、対応する式がツウィークウィンドウへ表示されます。変数ウィンドウ（f）は変数フェーダーを管理します。

- 横向き入力: `y=a*x^2`、`y=sin(x)`、`y=1/x`
- 縦向き入力: `x=5`、`x=sin(y)`
- 変数フェーダーを動かすとグラフも更新されます。
- 定義できない区間や不連続点では線を分割し、離れた点を結びません。
- 「傍記」をオンにすると式をグラフ付近へ表示し、軌跡に沿って移動・拡大縮小できます。
- 描画範囲の各端点は、●（含む）または○（含まない）として個別に指定できます。
- 陰関数や媒介変数表示は今後の拡張対象です。

## Codexによる直接開発

```bash

npm run build
npm run verify:repo
```

npm run verify
