# Graphanta v0.4.0-alpha.2

数学的な思考と表現を支援する、ローカルファーストの作図アプリです。

## 開発環境での起動

```bash
npm ci
npm run dev
```

`app.html`はViteの開発用入口です。リポジトリ直下の`index.html`は、ビルド済みの単体起動版です。

## 公開用ファイルの生成

```bash
npm run build
```

ビルド時に、Viteの生成物からCSSとJavaScriptを埋め込んだ単体版を作成します。

- リポジトリ直下の公開・ローカル起動用: `index.html`
- 検証用生成物: `dist/index.html`

GitHub Pagesは **Deploy from a branch / main / /(root)** を選択してください。Actionsワークフローは使用しません。`index.html`は通信なしで直接開けます。

## v0.4.0-alpha.2の主な変更

- ツウィーク見出しとヒントボタンの間隔を、横長・縦長・狭幅表示で約10pxに統一
- プロジェクト名の編集を1回の「元に戻す／やり直す」として記録
- 矢印キーの連続移動を短時間ごとにまとめ、1回の操作として元に戻せるよう改善
- 内容が変わらない操作を履歴へ追加しないようにし、履歴の無駄な消費を抑制
- 新規作成・ファイル読込・自動復旧時に別プロジェクトの履歴を持ち越さないよう修正
- 最新と一つ前の自動保存を復旧画面で比較し、選択して復元できるよう改善
- 復旧画面を閉じてもデータを残し、削除は明示操作と確認を必要とする仕様へ変更
- 内容が同一の自動保存では一つ前のバックアップを不必要に更新しないよう改善
- 手動保存時、および履歴操作で手動保存時点へ戻った際に、古い復旧データを整理
- プロジェクト読込時に重複した要素・数式・変数IDを自動修復
- キャンバス寸法や目盛り値を安全な範囲へ正規化し、異常な読込データによる不安定化を防止
- 入力欄の編集中でも `Ctrl/Cmd＋S`、`Ctrl/Cmd＋O`、`Ctrl/Cmd＋N`を利用可能
- v0.4.0-alpha.1までの保存状態表示、2世代自動保存、破損データ拒否、構造化数式、タッチ操作などを維持

## 数式入力の基本

| 入力 | 表示 |
|---|---|
| `a/b` | 分数 |
| `x^2` または `x^(n+1)` | 上付き |
| `a_1` または `a_(n+1)` | 下付き |
| `sqrt(x+1)` | 平方根 |
| `abs(x)` | 絶対値 |
| `frac(a+b,c-d)` | 分数 |
| `sqrt(b*x^2)/(a-1)/x` | 複分数 |

現在の構文はGraphanta独自の軽量形式です。将来の数式構造エディターでも、この保存形式を読み込めるよう互換性を維持します。

## Codexによる直接開発

リポジトリ直下の`AGENTS.md`に、GitHub Pages、完全オフライン、生成済み`index.html`、操作互換性、保存互換性、検証手順を記載しています。Codexへの接続と初回タスクは`CODEX_START.md`を参照してください。

推奨検証:

```bash
npm run check
npm run build
npm run verify:repo
```

まとめて実行する場合:

```bash
npm run verify
```
